### Asset Guidelines

**Adding New Assets:**
- Use appropriate formats (PNG for logos, SVG for diagrams)
- Optimize file sizes
- Use descriptive filenames
- Document usage in this file

**Formats:**
- **Images**: PNG, JPG, SVG
- **Diagrams**: SVG preferred for scalability
- **Icons**: SVG or PNG with multiple sizes
